# إضافة الأسئلة من بنك الأسئلة إلى الامتحانات

## نظرة عامة

- **امتحان المحاضرة**: يُنشأ نسخة من السؤال داخل الامتحان (نص، صورة، خيارات) مع الاحتفاظ بمرجع للسؤال الأصلي في البنك. الحذف أو تعديل الإجابة الصحيحة يخص الامتحان فقط ولا يغيّر البنك.
- **امتحان الكورس**: تُنسخ الأسئلة كاملة داخل جدول امتحان الكورس مع مرجع للبنك. التعديل في الامتحان لا يؤثر على البنك.

---

## 1. امتحان المحاضرة (Lecture Exam)

### الطلب

| | |
|--|--|
| **Method** | `POST` |
| **URL** | `/api/exams/:examId/questions/from-bank` |
| **Auth** | معلم (`teacher`) |

### Body (JSON)

```json
{
  "questionIds": [ 101, 102, 103 ]
}
```

- `questionIds`: مصفوفة أرقام — معرّفات الأسئلة في بنك الأسئلة (V1 أو V2).

### الاستجابة (201)

```json
{
  "message": "Questions added successfully",
  "count": 3,
  "examQuestionIds": [ 501, 502, 503 ]
}
```

- `count`: عدد الأسئلة التي تمت إضافتها.
- `examQuestionIds`: معرّفات الأسئلة **داخل الامتحان** (جدول `exam_questions`). تُستخدم في:
  - حذف السؤال من الامتحان: `DELETE /api/exams/:examId/questions/:examQuestionId`
  - تعديل الإجابة الصحيحة: `PATCH /api/exams/:examId/questions/:examQuestionId/correct-answer`
  - إخفاء/إظهار السؤال: `PATCH /api/exams/:examId/questions/:examQuestionId/visibility`

### 1.1 امتحان المحاضرة — إضافة مجموعة أسئلة بنص واحد (Bulk)

لإضافة عدة أسئلة دفعة واحدة من نص واحد (نفس صيغة امتحان الكورس: سؤال ثم a. b. c. d.):

| | |
|--|--|
| **Method** | `POST` |
| **URL** | `/api/exams/lecture/:examId/questions/bulk` |
| **Auth** | معلم (`teacher`) |

- **`:examId`**: معرّف امتحان المحاضرة (من جدول `exams`، نوع `exam`).

#### Body (JSON)

| الحقل | النوع | مطلوب | الوصف |
|--------|------|--------|--------|
| `text` أو `questionText` | string | نعم | النص الكامل للأسئلة (سطر السؤال ثم أربعة أسطر: a. b. c. d. لكل سؤال). |
| `correctAnswers` | array | لا | إجابات صحيحة بالترتيب، مثلاً `["C","D","D","D","C","A","D"]`. إن لم يُرسَل، تُعامل كل الأسئلة إجابتها الصحيحة A. |

#### شكل النص (مثل امتحان الكورس)

```
أي الجزيئات التالية يحتوي على أقل عدد من ذرات الأكسجين؟
a. الجلوكوز
b. الفركتوز
c. الدي أوكسي ريبوز
d. الريبوز

أي العناصر التالية لا ينتج من التحلل البيوكيميائي لجميع البروتينات؟
a. الكربون
b. النيتروجين
c. الأكسجين
d. الكبريت
```

#### مثال طلب

```json
{
  "text": "أي الجزيئات التالية يحتوي على أقل عدد من ذرات الأكسجين؟\na. الجلوكوز\nb. الفركتوز\nc. الدي أوكسي ريبوز\nd. الريبوز\n\nأي العناصر التالية لا ينتج من التحلل البيوكيميائي لجميع البروتينات؟\na. الكربون\nb. النيتروجين\nc. الأكسجين\nd. الكبريت",
  "correctAnswers": ["C", "D"]
}
```

#### الاستجابة (201)

```json
{
  "message": "تمت إضافة 2 سؤال",
  "count": 2,
  "questions": [ { "id": 501, "question_text": "...", "choices": [...] }, ... ],
  "examId": 123
}
```

## 2. امتحان الكورس (Course-Level Exam)

### الطريقة الأولى: نفس الـ endpoint مع تمييز تلقائي

| | |
|--|--|
| **Method** | `POST` |
| **URL** | `/api/exams/:examId/questions/from-bank` |
| **Auth** | معلم |

إذا كان `:examId` يخص امتحان كورس (course-level)، يتم التعامل معه كامتحان كورس.

### الطريقة الثانية: endpoint مخصّص لامتحان الكورس

| | |
|--|--|
| **Method** | `POST` |
| **URL** | `/api/exams/course-level/:examId/questions/from-bank` |
| **Auth** | معلم |

### Body (JSON)

```json
{
  "questionIds": [ 201, 202, 203 ]
}
```

- `questionIds`: معرّفات الأسئلة في بنك الأسئلة (V1 أو V2).

### الاستجابة (201)

```json
{
  "message": "Questions added successfully to course-level exam",
  "count": 3
}
```

أو عند استخدام الـ endpoint الموحّد:

```json
{
  "message": "Questions added successfully",
  "count": 3
}
```

- حذف سؤال من امتحان الكورس: `DELETE /api/course/course-exam/question/:questionId`  
  (يمكن استخدام معرّف صف السؤال في الامتحان أو معرّف السؤال في البنك).
- تعديل الإجابة الصحيحة: `PATCH /api/course/course-exam/question/:questionId/correct-answer`  
  (يُحدَّث عمود `correct_answer` في جدول الامتحان فقط).
- **إضافة/تحديث صورة لسؤال:** `PATCH /api/course/course-exam/question/:questionId/image` مع رفع ملف (multipart، الحقل `questionImage`). انظر القسم التالي.

---

## 2.1 إضافة صورة لسؤال في امتحان الكورس

| | |
|--|--|
| **Method** | `PATCH` |
| **URL** | `/api/course/course-exam/question/:questionId/image` |
| **Auth** | معلم (`teacher`) |

- **`:questionId`**: معرّف السؤال في امتحان الكورس (معرّف الصف في `course_level_exam_questions`، أو معرّف السؤال في البنك حسب السياق).

### Body (multipart/form-data)

| الحقل | النوع | مطلوب | الوصف |
|--------|------|--------|--------|
| `questionImage` | file | نعم | ملف الصورة (jpeg, jpg, png, gif, webp — حد أقصى 10MB). |

### الاستجابة (200)

```json
{
  "message": "تمت إضافة صورة السؤال بنجاح",
  "question": { "id": 101, "question_text": "...", "question_image": "https://...", ... },
  "questionImage": "https://..."
}
```

## 3. امتحان الكورس — إضافة مجموعة أسئلة بنص واحد (Bulk)

لإضافة عدة أسئلة دفعة واحدة من نص واحد (نسخ/لصق) لامتحان الكورس، استخدم:

| | |
|--|--|
| **Method** | `POST` |
| **URL** | `/api/exams/:examId/questions/bulk` |
| **Auth** | معلم (`teacher`) |

- **`:examId`**: معرّف امتحان الكورس (course-level exam). يمكن الحصول عليه من واجهة الكورس أو من API جلب امتحان الكورس.

### Body (JSON)

| الحقل | النوع | مطلوب | الوصف |
|--------|------|--------|--------|
| `text` أو `questionText` | string | نعم | النص الكامل للأسئلة (انظر الشكل أدناه). |
| `correctAnswers` | array | لا | إجابات صحيحة بالترتيب، مثلاً `["C","D","D","D","C","A","D"]`. إن لم يُرسَل، تُعامل كل الأسئلة إجابتها الصحيحة A. |

### شكل النص

كل سؤال يتكوّن من:
1. سطر أو أكثر لنص السؤال.
2. أربعة أسطر بالترتيب: `a.` ثم `b.` ثم `c.` ثم `d.` (مع النص بعد النقطة).

يمكن وضع سطر فاضي بين الأسئلة أو عدم وضعه — النظام يفسّر السطور تلقائياً.

**مثال قصير:**

```
أي مما يلي لا يعتبر من الجزيئات العضوية الصغيرة؟
a. الأحماض النووية
b. الأحماض الأمينية
c. الأحماض الدهنية
d. لا توجد إجابة صحيحة

أي المركبات الآتية يحتوي على أقل عدد من جزيئات الجلوكوز؟
a. السليلوز
b. السكروز
c. النشا
d. الكيتين
```

**مثال كامل (مجموعة أسئلة مرة واحدة):**

```
أي الجزيئات التالية يحتوي على أقل عدد من ذرات الأكسجين؟
a. الجلوكوز
b. الفركتوز
c. الدي أوكسي ريبوز
d. الريبوز

أي العناصر التالية لا ينتج من التحلل البيوكيميائي لجميع البروتينات؟
a. الكربون
b. النيتروجين
c. الأكسجين
d. الكبريت

أي المواد الغذائية التالية هي الأعلى مصدرًا للطاقة؟
a. 30 جم كربوهيدرات
b. 18 جم كربوهيدرات
c. 20 جم بروتينات
d. 13 جم ليبيدات

أي مما يلي يعد مصدر طاقة مخزن في النباتات؟
a. الجلوكوز
b. السليلوز
c. الجليكوجين
d. النشا

كم عدد النيوكليوتيدات للأحماض النووية الريبوزية منقوصة الأكسجين؟
a. نوع واحد فقط
b. نوعان
c. 4 أنواع
d. 8 أنواع

عدد العناصر الموجودة في DNA يزداد عن عدد العناصر الموجودة في جميع البروتينات بـ …
a. عنصر واحد
b. عنصران
c. ثلاثة عناصر
d. 4 عناصر

تتشابه البروتينات والليبيدات في أن كلا منهما يدخل في تكوين …
a. الإنزيمات
b. الهرمونات
c. الكروموسومات
d. الإنزيمات والهرمونات
```

### مثال طلب (سؤالان)

```json
{
  "text": "أي مما يلي لا يعتبر من الجزيئات العضوية الصغيرة؟\na. الأحماض النووية\nb. الأحماض الأمينية\nc. الأحماض الدهنية\nd. لا توجد إجابة صحيحة\n\nأي المركبات الآتية يحتوي على أقل عدد من جزيئات الجلوكوز؟\na. السليلوز\nb. السكروز\nc. النشا\nd. الكيتين",
  "correctAnswers": ["A", "B"]
}
```

### مثال طلب (المجموعة الكاملة مع الإجابات الصحيحة)

إذا كانت الإجابات الصحيحة بالترتيب مثلاً: ج، د، د، د، ج، أ، د:

```json
{
  "text": "أي الجزيئات التالية يحتوي على أقل عدد من ذرات الأكسجين؟\na. الجلوكوز\nb. الفركتوز\nc. الدي أوكسي ريبوز\nd. الريبوز\n\nأي العناصر التالية لا ينتج من التحلل البيوكيميائي لجميع البروتينات؟\na. الكربون\nb. النيتروجين\nc. الأكسجين\nd. الكبريت\n\nأي المواد الغذائية التالية هي الأعلى مصدرًا للطاقة؟\na. 30 جم كربوهيدرات\nb. 18 جم كربوهيدرات\nc. 20 جم بروتينات\nd. 13 جم ليبيدات\n\nأي مما يلي يعد مصدر طاقة مخزن في النباتات؟\na. الجلوكوز\nb. السليلوز\nc. الجليكوجين\nd. النشا\n\nكم عدد النيوكليوتيدات للأحماض النووية الريبوزية منقوصة الأكسجين؟\na. نوع واحد فقط\nb. نوعان\nc. 4 أنواع\nd. 8 أنواع\n\nعدد العناصر الموجودة في DNA يزداد عن عدد العناصر الموجودة في جميع البروتينات بـ …\na. عنصر واحد\nb. عنصران\nc. ثلاثة عناصر\nd. 4 عناصر\n\nتتشابه البروتينات والليبيدات في أن كلا منهما يدخل في تكوين …\na. الإنزيمات\nb. الهرمونات\nc. الكروموسومات\nd. الإنزيمات والهرمونات",
  "correctAnswers": ["C", "D", "D", "D", "C", "A", "D"]
}
```

### الاستجابة (201)

```json
{
  "message": "تمت إضافة 7 سؤال",
  "count": 7,
  "questions": [ { "id": 101, "question_text": "...", "option_a": "...", ... }, ... ]
}
```

## ملخص

| نوع الامتحان | إضافة من البنك | إضافة مجموعة أسئلة بنص واحد | بعد الإضافة |
|--------------|----------------|------------------------------|-------------|
| **محاضرة** | `POST /api/exams/:examId/questions/from-bank` مع `questionIds` | `POST /api/exams/lecture/:examId/questions/bulk` مع `text` أو `questionText` واختياريًا `correctAnswers` | استخدم `examQuestionIds` أو معرّفات الأسئلة من الاستجابة للحذف وتعديل الإجابة والإظهار. |
| **كورس** | `POST /api/exams/:examId/questions/from-bank` أو `POST /api/exams/course-level/:examId/questions/from-bank` مع `questionIds` | `POST /api/exams/:examId/questions/bulk` مع `text` أو `questionText` واختياريًا `correctAnswers` | الحذف وتعديل الإجابة عبر مسارات امتحان الكورس؛ التعديل في الامتحان فقط. |

- لا يتم تعديل أو حذف السؤال الأصلي في بنك الأسئلة عند الحذف أو تغيير الإجابة الصحيحة داخل الامتحان.
- **إضافة مجموعة أسئلة لامتحان الكورس دفعة واحدة:** استخدم `POST /api/exams/:examId/questions/bulk` حيث `examId` = معرّف امتحان الكورس، وأرسل في الـ body الحقل `text` (أو `questionText`) يحتوي كل الأسئلة بصيغة: سطر السؤال ثم `a.` `b.` `c.` `d.` لكل سؤال.
