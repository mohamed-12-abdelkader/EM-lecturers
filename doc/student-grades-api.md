# Student Grades API Documentation

## نظرة عامة
هذا الـ API يتيح للمدرسين إدارة درجات الطلاب في امتحانات المجموعات الدراسية.

## نقاط النهاية (Endpoints)

### 1. إضافة درجة طالب في امتحان

**POST** `/api/student-grades/`

**الوصف:** إضافة درجة طالب في امتحان مجموعة معين

**الصلاحيات:** المدرس أو المدير فقط

**Request Body:**
```json
{
  "exam_name": "امتحان الوحدة الأولى",
  "student_id": 123,
  "grade": 85.5,
  "notes": "أداء ممتاز في الجزء النظري"
}
```

**الحقول المطلوبة:**
- `exam_name`: اسم الامتحان (نص)
- `student_id`: معرف الطالب (رقم)
- `grade`: الدرجة (رقم عشري)
- `notes`: ملاحظات (اختياري، نص)

**Response (201):**
```json
{
  "message": "تم إضافة الدرجة بنجاح",
  "grade": {
    "id": 1,
    "exam_name": "امتحان الوحدة الأولى",
    "group_name": "مجموعة الرياضيات",
    "student_name": "أحمد محمد",
    "student_id": 123,
    "grade": 85.5,
    "total_grade": 100,
    "notes": "أداء ممتاز في الجزء النظري",
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-15T10:30:00Z"
  }
}
```

**أخطاء محتملة:**
- `400`: بيانات مطلوبة - إذا كانت البيانات غير مكتملة
- `404`: طالب غير موجود - إذا كان الطالب غير موجود في النظام
- `400`: دور خاطئ - إذا كان المستخدم ليس طالب
- `404`: امتحان غير موجود - إذا كان الامتحان غير موجود في مجموعات المدرس
- `400`: طالب غير موجود في المجموعة - إذا كان الطالب ليس في المجموعة
- `400`: درجة غير صحيحة - إذا كانت الدرجة تتجاوز الدرجة الكلية أو سالبة

### 2. جلب درجات طالب معين

**GET** `/api/student-grades/student/:studentId`

**الوصف:** جلب جميع درجات طالب معين في امتحانات المدرس

**الصلاحيات:** المدرس أو المدير فقط

**Response (200):**
```json
{
  "student": {
    "id": 123,
    "name": "أحمد محمد"
  },
  "grades": [
    {
      "id": 1,
      "grade": 85.5,
      "notes": "أداء ممتاز",
      "created_at": "2024-01-15T10:30:00Z",
      "updated_at": "2024-01-15T10:30:00Z",
      "exam_name": "امتحان الوحدة الأولى",
      "total_grade": 100,
      "exam_date": "2024-01-15",
      "group_name": "مجموعة الرياضيات",
      "group_id": 1
    }
  ],
  "total_exams": 1,
  "average_grade": 85.5
}
```

### 4. تحديث درجة طالب

**PUT** `/api/student-grades/:gradeId`

**الوصف:** تحديث درجة طالب موجودة

**الصلاحيات:** المدرس أو المدير فقط

**Request Body:**
```json
{
  "grade": 90.0,
  "notes": "تم تصحيح الدرجة بعد مراجعة إضافية"
}
```

**الحقول:**
- `grade`: الدرجة الجديدة (اختياري، رقم عشري)
- `notes`: ملاحظات جديدة (اختياري، نص)

**Response (200):**
```json
{
  "message": "تم تحديث الدرجة بنجاح",
  "grade": {
    "id": 1,
    "exam_name": "امتحان الوحدة الأولى",
    "grade": 90.0,
    "total_grade": 100,
    "notes": "تم تصحيح الدرجة بعد مراجعة إضافية",
    "updated_at": "2024-01-15T11:00:00Z"
  }
}
```

## أمثلة استخدام

### مثال 1: إضافة درجة طالب
```bash
curl -X POST "http://localhost:8000/api/student-grades/" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "exam_name": "امتحان الوحدة الأولى",
    "student_id": 123,
    "grade": 85.5,
    "notes": "أداء ممتاز في الجزء النظري"
  }'
```

### مثال 2: جلب درجات طالب
```bash
curl -X GET "http://localhost:8000/api/student-grades/student/123" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### مثال 3: جلب درجات امتحان
```bash
curl -X GET "http://localhost:8000/api/student-grades/exam/امتحان%20الوحدة%20الأولى" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### مثال 4: تحديث درجة
```bash
curl -X PUT "http://localhost:8000/api/student-grades/1" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "grade": 90.0,
    "notes": "تم تصحيح الدرجة"
  }'
```

## ملاحظات مهمة

1. **التحقق من الصلاحيات:** المدرس يمكنه فقط إدارة درجات الطلاب في مجموعاته
2. **التحقق من البيانات:** يتم التحقق من وجود الطالب وأنه طالب فعلاً
3. **التحقق من المجموعة:** يتم التحقق من أن الطالب موجود في المجموعة
4. **التحقق من الدرجة:** الدرجة لا يمكن أن تتجاوز الدرجة الكلية أو تكون سالبة
5. **التحديث التلقائي:** إذا كانت الدرجة موجودة بالفعل، سيتم تحديثها بدلاً من إنشاء سجل جديد
6. **التواريخ:** يتم تسجيل تاريخ الإنشاء والتحديث تلقائياً

---

## رموز الأخطاء

- `400`: خطأ في البيانات المرسلة
- `401`: غير مصرح (مطلوب تسجيل دخول)
- `403`: غير مصرح (لا توجد صلاحية)
- `404`: المورد غير موجود
- `500`: خطأ في الخادم
