# WhatsApp Exam Assistant (مساعد الامتحانات)

يوسّع خدمة `teacher_exam_builder_bot` الموجودة إلى Workflow حقيقي مع state machine محفوظة في DB، مع محادثة طبيعية وتعديل امتحانات على Exam ID حقيقي.

## تشغيل

1. طبّق الـ migration: `1780970000000_wa_exam_assistant_workflow.sql`
2. من لوحة واتساب: فعّل خدمة **مساعد الامتحانات** واربط لها session.
3. المدرس يراسل من رقم واتساب المسجّل في حسابه.

## Flows المدعومة

### محادثة طبيعية
- تحية / شكر / سؤال عن الإمكانيات → رد قصير بالعامية المصرية **بدون** إنشاء امتحان.
- رسالة غير واضحة → يسأل عن المقصود.
- السياق (`recent_turns` + حالة الجلسة) يُحفظ في `wa_exam_assistant_sessions.context`.

### من بنك الأسئلة
طلب إنشاء واضح → (اختياري) تأكيد مهمة مجدولة اليوم → تحديد الدرس/الإعدادات → اقتراح أسئلة عبر `ExamBuilderChatbotService` → مراجعة عبر رابط `/exam-builder-chat/:sessionId/approve` → اختيار النوع (عام/واجب/شامل) → اختيار كورس/محاضرة → مسودة `is_visible=false` → نشر صريح.

### من ملفات/صور
إرسال PDF/صور (JPG/PNG/WEBP) مع فهم الـ caption:
- بدون caption → يسأل: إنشاء / مراجعة / إضافة للامتحان الحالي
- «اعمل امتحان» → مسار إنشاء
- «راجع» → استخراج وعرض بدون إنشاء
- «ضيفهم على الامتحان» → إضافة على `draft_exam_id` الحالي

تجميع حتى «خلصت» → استخراج عبر `MistralQuestionExtractionService` → باقي المسار حسب النية.

### تعديل بعد الإنشاء
على المسودة/آخر امتحان في الجلسة (`draft_exam_id` / `recent_exam_ids`) عبر الخدمات الحالية:
- احذف السؤال N
- درجة السؤال N
- الإجابة الصحيحة (امتحان شامل)
- إضافة أسئلة مستخرجة من ملف

قبل المسودة: التعديل عبر `ExamBuilderChatbotService.adjustSession` كما كان.

## الميديا وحدود الحجم

- الـ gateway (`wwebjs`) يحمّل الميديا ويرسلها base64 على الويبهوك.
- API يقبل JSON حتى **25mb** (`express.json`) لاستيعاب base64.
- بعد decode: حد حفظ مساعد الامتحانات **15MB** للملف الفعلي.
- أخطاء `media_error` تُترجم لرسائل دقيقة (تحميل / صيغة / حجم / تالف) وليست دائمًا «الملف كبير».

### تشغيل الإنتاج
- ارفع `client_max_body_size` في nginx (مثلاً `30m`) لمسار `/api/webhooks/whatsapp`.
- تأكد أن wwebjs يمرّر صور **ومستندات PDF**، وحد التحميل هناك متوافق مع الاستخدام الفعلي.

## Admin

`GET /api/whatsapp/admin/exam-assistant/sessions`

## ملاحظات

- لا يُنشر امتحان بدون موافقة صريحة («انشر» / «موافق على النشر»).
- Tenant/Teacher isolation عبر رقم واتساب المدرس + فحص ملكية الامتحان عند التعديل.
- خدمات واتساب الأخرى (علمي / إبداعي / دعم …) لم تتأثر.
